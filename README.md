# 我的第一个 GitHub 仓库 · 经济学小工具

> 这个仓库是我学习 GitHub 和 Python 经济学的起点。
> 建立日期：2026-02

## 这是什么

一个零依赖（只用 Python 标准库）的经济学计算小工具，配合一份 GitHub 入门笔记。
目的是：**用最小的成本，把一个真实项目推上 GitHub，从而学会整套流程。**

## 里面有什么

| 文件 | 作用 |
| --- | --- |
| `START_HERE.md` | 手把手第一天：注册、配代理、第一次提交、第一次推送 |
| `ECON_ROADMAP.md` | 经济学 / 量化分析方向的推荐仓库和 4 周学习计划 |
| `GIT_CHEATSHEET.md` | Git 命令速查表，忘了就回来查 |
| `hello_econ.py` | 第一个 Python 小工具：复利、现值、CAGR、通胀调整、一元回归 |
| `.gitignore` | 告诉 Git「哪些文件不要传上去」 |

## 怎么运行

需要 Python 3.10 以上（我电脑上是 3.14）。

```bash
python hello_econ.py
```

输出示例：

```
【1】复利：10,000 元，年化 7%，30 年后
     终值 = 76,122.55 元，是本金 7.6 倍
     翻倍时间：精确 10.24 年 / 72法则估 10.29 年

【3】通胀：1,000,000 元，20 年后，年通胀 3%
     实际购买力 = 553,675.75 元（缩水 44.6%）

【5】回归：教育年限 -> 月薪（n = 15，模拟数据）
     回归方程：月薪 = -5,790 + 1,029 × 教育年限
     R^2 = 0.956
```

> 如果看到中文乱码，先执行 `chcp 65001` 再运行。
